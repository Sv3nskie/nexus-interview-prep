Run it yourself

NEXUS stores data in MongoDB and needs one AI engine. With Docker it's two commands.

git clone https://github.com/Sv3nskie/nexus-interview-prep
cd nexus-interview-prep
docker compose up -d --build     # → http://interview.localhost

# or without Docker (Node 22+):
npm install && npm run dev       # → http://localhost:5173
